в комплекте 2 основных файла:
0t,0m	- 1617136 байт начало прошивальщика в вариантах для флеша от toshiba/sandisk/hynix и intel/micron соответственно
2	- 1249040 байт конец прошивальщика

между ними нужно вставить
fw.bin - 1479168 прошивка

известные длины прошивок:
954880	0xE9200		0.2
950784	0xE8200		0.2
1475072	0x168200	0.8
1479168	0x169200	все остальные
использовать недавно появившиеся версии прошивок длиной 1544704 (21.2, 61.2, 91.2 итп) с помощью данного комплекта нельзя. но они в массе требуют разлочки и в принципе не совместимы с данным прошивальщиком.

для формирования прошивальщика используя прошивку длиной 1479168:

copy /b 0 + fw.bin + 2 fw.exe

пример в s11-flasher.cmd

на выходе получается fw.exe

для прошивок меньшего обьема, например:

copy /b 0 + fw.bin + 128k +4k + 2 fw.exe
copy /b 0 + fw.bin + 128k + 2 fw.exe
copy /b 0 + fw.bin + 4k + 2 fw.exe

fw.bin брать на usbdev.ru или извлекать из toolbox/complete и прочего.
http://www.usbdev.ru/?wpfb_dl=6583

версия прошивки должна соответствовать примененному флешу
0x.x - mlc/tsb15
1x.x - tlc/tsb15
2x.x - mlc/micron3d (32L)
5x.x - tlc/hynix (16nm)
6x.x - tlc/tsb3d (bics2 - 48L и bics3 - 64L, bics4 - 96L), поддержка bics4 вероятно с 61.3 от 2019 года
7x.x - tlc/micron3d (B0KB)
8x.x - mlc/tsb15 (ufs?)
9x.x - mlc/tsb15
Ax.x - tlc/intel3d (B0KB)
Bx.x - tlc/micron3dv2 (64L - B16A/B17A)
Kx.x - qlc/intel3dv2 (64L - N18A)
Ex.x - tlc/hynix3d (72L)
BA.x - tlc/micron3dv2 (64L - B17A)
Jx.x - tlc/micron3dv3 (96L - B27A)???

Прошивок данных версий на момент написания этого файла не найдено:
Ax.x, Kx.x, Ex.x, Jx.x

у дисков с asolid as2258 вроде бы отличный от прочих ROM, и стандартные прошивки он не принимает.
так же там отдельная нумерация прошивок относительно флеша. встречались:
23.0 - Micron L06B
72.0 - Micron B0KB
83.0 - IMFT B16A,B17A
A3.0 - Micron B27A
решение данного вопроса на данный момент неизвестно.

здесь можно исправить выводимую в окне версию на реальную, для красоты:
0x134C1C-0x134C1F: firmware version for gui

здесь длину для прошивок обьемом меньше 1479168, это необходимо:
0x18A846/7: firmware lenght

здесь название модели диска, не более 18 символов, если меньше - дополнить пробелами (иначе диск после прошивке будет иметь модель "SSD Smartbuy 120GB"):
0x135388/18: Model name

прошивальщик работает в ahci режиме с драйверами msahci/storahci/rst(не rste). с pciide/intelide - не факт. с прочими не проверял.
если вылетает на 85% ("ISP Jump ..") - снять с диска питание и подключить и посмотреть на результат, иногда оживает, иногда нет.
как с этим бороться пока не очень понятно.

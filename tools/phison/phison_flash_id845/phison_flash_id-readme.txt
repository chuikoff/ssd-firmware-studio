Программа предназначена для определения конфигурации флеш-памяти у ssd дисков на контроллере Phison 3105/3108/3109/3110/3111, например Smartbuy Ignition4.

Системные требования - Windows XP/SP2 и выше, возможно использование x86 и x64 версий. Можно использовать Windows PE основанные на этих же версиях. Требуется запуск с правами администратора (под системами Vista/выше производится запрос на получение прав).
Диск должен быть подключен к SATA контроллеру (подключение через firewire не поддерживается), поддерживается работа со стандартными драйверами IDE и AHCI от Microsoft, Intel RST. Работоспособность с другими драйверами не проверялась. Наверняка не будет работать с драйверами контроллеров из раздела "SCSI and RAID controllers" (кроме версий RST начиная с 11.7).
Так же возможна работа через некоторые usb-sata мосты, например asmedia asm105x/115x, jmicron jm[s]20329/539/578, initio inic1608 и некоторые другие.
В IDE режиме контроллера во избежание проблем с его драйверами (pciide, intelide итп) рекомендуется использовать версию из каталога for_ide_mode\phison_flash_id(pciide).exe у которой отключено чтение списков счетчиков стираний.

Для запуска программе нужно указать номер диска в системе в виде параметра, его можно посмотреть в консоли "Управление компьютером"->"Управление дисками".
Например:
phison_flash_id 2
phison_flash_id 2b - сохранить данные в двоичном виде
phison_flash_id 2d - отключить чтение списков дефектов и поблочных счетчиков стираний
phison_flash_id 2w - сохранить рабочую прошивку (работает для ps3110, экспериментально для ps3109/ps3111)
phison_flash_id 2y - не выводить запрос нажатия любой клавиши перед завершением
phison_flash_id 2x - экспериментальные функции, сейчас - сохранение nand parameter page по всем банкам
phison_flash_id 2n - сохранить в файл отчета серийный номер (по умолчанию не сохраняется)
параметры b/d/w/y/x/n можно комбинировать

Если запустить без параметров, то будет выведен список доступных дисков и запрос номера диска.
Например:
---
 0: V4-CT128V4SSD2
 2: OCZ-VERTEX4
Please select drive number:
---
после номера диска, без пробела, можно использовать те же параметры, что и в командной строке.

Результат выводится на экран, а так же в расширенном виде сохраняется в текстовый файл phison_flash_id.txt. Туда же дублируются и сообщения об ошибках.
phison_flash_id_ec.txt - поблочные списки счетчиков стираний
phison_flash_id_smart.txt - расширенный старт (только для s10)
phison_flash_id_ppg.txt - декодированный nand parameter page (если есть)

Примечание:
Начиная с 2018 года в прошивках ps3111 появилась блокировка доступа к vendor specific командам, что препятствует работе программы.
В частности это касается прошивок 21.2,61.2,91.2 и более новых, например:
S11fw: SBFM21.2, 2017Dec 5
S11fw: SBFM61.2, 2018Jan24
S11fw: SBFM61.2, 2018Mar23
S11fw: SBFM91.2, 2018Jan24
С версии 0.8 процедура разблокировки для S11 встроена.

Если она почему-то не сработала, можно попытаться использовать сторонние средства:
s11_unlocker8 - http://vlo.name:3000/tmph/s11_unlocker.rar
Так же в качестве универсального unlocker'а (работающего так же в "satafirm") можно использовать свежие версии phison toolbox (например 1.18), например с сайта patriot'а.

http://vlo.name:3000/tmph/parpg.rar - декодер nand parameter page

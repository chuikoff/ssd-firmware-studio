Программа предназначена для определения конфигурации флеш-памяти у ssd дисков на контроллерах SMI SM224x/225x, например Adata SP610,
также SD карт на контроллерах SM26xx/27xx и CF карт на контроллерах SM22x/223x.

Для запуска программе нужно указать номер диска в системе в виде параметра, его можно посмотреть в консоли "Управление компьютером"->"Управление дисками".
Например:
smi_flash_id_ata 1
smi_flash_id_ata 1y
smi_flash_id_usb 1
smi_flash_id_usb 1u

u - для обхода проверки модели контроллера, так же бывает нужно в rom mode
y - не ожидать нажатия клавиши перед завершением

Если запустить без параметров, то будет выведен список доступных дисков и запрос номера диска.
Например:
---
 0: SAMSUNG HD103UJ
 1: SAMSUNG HD204UI
Please select drive number:
---

Общие ограничения и особенности:
- на время работы нежелательна дисковая активность с проверяемым диском
- результат выводится на экран и сохраняется в файл smi_flash_id.txt, перезаписывая его.
- проверена работоспособность на sata ssd контроллерах SM2246EN/XT, SM2244LT, SM2250, SM2256/S, SM2258/XT, SM2259/XT/XT2.
- проверена работоспособность на pata/cf контроллерах SM223.
- проверена работоспособность на sd/mmc контроллерах SM2683,SM2685,SM2689,SM2702,SM2703,SM2705.
- если на диске есть разделы в пределах первых ~12MB, то работает только под xp/2003, под vista+ не будет (ATA версия может сработать, если у раздела отнята буква).
- выводит список дисков и запрос номера, если он не указан в командной строке.
- выводит модель контроллера.
- в случае сообщения "Compatible SSD not found(1), exit!" для sata ssd в rom mode нужно запустить с ключиком 'u'.
- в случае сообщения "Compatible SSD not found(2), exit!" можно попробовать запустить с ключиком 'u'.

для USB(ATA) версии:
- работает только при подключении диска через usb-sata мосты без uasp, через sata работает только в ide (не ahci/raid) режиме.
- в rom mode может работать и в ahci
- для неподдерживаемых дисков может быть выполнена запись на диск в сектор 21930. перед завершением программа проверяет его целостность и восстановливает.
- работает с некоторым CF картами на контроллерах от SMI, вставленными в USB кардридер
- работает с SD картами на контроллерах от SMI, выводит модель контроллера, дату прошивки и идентификаторы флеша.
  после определения карту обязательно необходимо вытащить из слота и вставить обратно для дальнейшего использования.
- может не работать при подключении диска через переходник в UASP режиме

для ATA версии:
- работает только при подключении диска через ATA контроллер с драйверами, например от MS (pciide, msahci, storahci), IRST.
- работает при подключении диска через некоторые usb-sata мосты, например asm105x или jm20329/jms5xx
- возможно работает с некоторым CF картами подключенными через переходник к ATA/SATA, но не через картридер.

для SD версии:
- работает с SD картами на контроллерах от SMI, выводит модель контроллера, дату прошивки и идентификаторы флеша.
- если на диске есть разделы в пределах первых ~12MB, то идентификаторы флеша отображаются только под xp/2003, под vista+ не будут.

для USB версии:
- работает с usb flash на контроллерах от SMI, выводит модель контроллера, дату прошивки и идентификаторы флеша.

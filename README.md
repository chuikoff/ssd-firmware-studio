# SSD Firmware Studio Pro ⚡

Универсальный графический мастер для диагностики, подбора прошивок и восстановления твердотельных накопителей (SSD) на контроллерах **Phison**, **Silicon Motion (SMI)** и **Maxio**.

---

## 🛠 Возможности

* **Мастер восстановления в 4 шага:**
  1. **Выбор накопителя:** Сканирование физических дисков в Windows с определением шины (SATA, NVMe, USB), разделов и **защитой системного диска (C:)** от случайной перезаписи.
  2. **Низкоуровневый опрос контроллера и памяти:** Чтение физического Flash ID (FID), определение типа NAND (Hynix, Micron, Toshiba/Kioxia, Intel, YMTC), ревизии текущей прошивки и режима работы (Normal / ROM Safe Mode).
  3. **Интеллектуальный подбор прошивок:** Анализ локальной базы прошивок, определение поколения и ранжирование по совместимости с обнаруженными кристаллами памяти.
  4. **Сборка и запуск прошивальщика:** Автоматическая генерация бинарного исполняемого образа `fw.exe` (для Phison S11) с корректными стабами (`0t` / `0m` / `0n`) либо подготовка фабричных пакетов MPTool с повышением привилегий (UAC RunAs).
* **Поддержка USB-мостов:** Встроенный модуль `bridge_probe` опрашивает SSD за переходниками (Realtek RTL9210B, JMicron JMS583, ASMedia ASM236) через прямые SCSI/ATA Pass-Through IOCTL-команды Windows.
* **Ручной ввод отчетов:** Возможность вставить сырой вывод консольных утилит (например, с профильных форумов или других ПК) для парсинга и подбора прошивки.
* **Легковесный интерфейс:** Работает на базе встроенного системного движка **Microsoft Edge WebView2** — приложение не требует тяжелого балласта Electron и потребляет минимум системных ресурсов.

## 🔌 Поддерживаемые контроллеры

| Вендор | Поддерживаемые чипы | Утилиты опроса / прошивки |
|---|---|---|
| **Phison** | PS3111-S11, PS5012-E12, PS5013-E13, PS3110-S10 | `phison_flash_id`, `s11-flasher` (автосборка `fw.exe`) |
| **Silicon Motion (SMI)** | SM2258XT, SM2259XT, SM2246EN/XT, SM2262/63 | `smi_flash_id` (ATA / USB / NVMe), SMI MPTool |
| **Maxio** | MAS0902, MAS1102, MAP1202, MAP1602, MK8115 | `jm_fid`, `maxio_nvme_fid`, Maxio MPTool |

## 🚀 Быстрый старт

### Требования
* Windows 10 / 11 (64-bit)
* Python 3.10+
* Microsoft Edge WebView2 Runtime (предустановлен в современных версиях Windows 10/11)
* Права **Администратора** (необходимы для прямого доступа к физическим дискам `\\.\PhysicalDriveX`)

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск приложения
Запустите командный файл:
```cmd
start_app.bat
```
*(Скрипт автоматически запросит права Администратора через Windows UAC).*

Или запустите напрямую через Python:
```bash
python app.py
```

Опционально можно запустить веб-режим в стандартном браузере:
```bash
python app.py --web
```

## 📦 Сборка автономного EXE (PyInstaller)

Для сборки автономного приложения без необходимости устанавливать Python на других ПК:
```bash
python scripts/build_exe.py
```
Готовый дистрибутив будет собран в папке `dist/SSD_Firmware_Studio/`.

## 📂 Структура проекта

```
ssd-firmware-studio/
├── app.py                      # Точка входа приложения (запуск WebView2 или веб-сервера)
├── server.py                   # Опциональный REST API сервер (FastAPI)
├── start_app.bat               # Скрипт запуска с автозапросом UAC (Admin)
├── core/
│   ├── detector.py             # Парсеры отчетов и опрос контроллеров (SMI / Phison / Maxio)
│   ├── bridge_probe.py         # Низкоуровневый опрос накопителей через USB-мосты (SCSI Pass-Through)
│   ├── firmware_matcher.py     # Логика ранжирования и подбора совместимых прошивок
│   ├── flasher.py              # Сборщик бинарных fw.exe и запуск MPTool
│   ├── paths.py                # Разрешение путей каталогов и бандлов
│   ├── scanner.py              # Сканирование физических дисков через PowerShell WMI
│   └── studio_api.py           # Двусторонний JS-Bridge API
├── ui/                         # Интерфейс приложения (HTML5, современный CSS, JavaScript)
├── tools/                      # Низкоуровневые утилиты диагностики
├── firmware/                   # Локальная база бинарных файлов прошивок (.BIN)
└── scripts/                    # Вспомогательные скрипты сборки и тестирования
```

## ⚠️ Внимание и дисклеймер

Прошивка SSD — низкоуровневая операция. Всегда проверяйте:
1. Что целевой диск выбран правильно и **не является системным или диском с важными данными**.
2. В процессе прошивки все данные на целевом накопителе будут **полностью удалены**.
3. При неудачном сбое питания или некорректном выборе типа памяти накопитель может перейти в состояние кирпича, требующее замыкания тестпоинтов (ROM Mode) для повторного восстановления.
